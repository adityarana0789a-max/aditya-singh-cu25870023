# Java Lab Sheet 10 – File Handling

Each question has a separate folder containing `Main.java`, `output.txt`, and any sample input file needed.

## How to run
1. Open a question folder in VS Code / terminal.
2. Compile: `javac Main.java`
3. Run: `java Main`
4. For interactive programs, enter the sample input shown in `output.txt`.

Note: Q2 reads the provided `student.txt` sample file. Q4 appends to `students.txt`. Q7 displays an absolute path that depends on your computer. Q9 needs five student records as input.
