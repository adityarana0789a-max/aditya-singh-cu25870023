# Java Lab Sheet 09 – Collections

**Based on:** FOUNDATION OF JAVA LAB SHEET – 9 (uploaded PDF)  
**Total:** 15 programs (Q1–Q14 and Q15; the PDF labels the last question as “Q315”).

## Contents
Each question has its own folder containing:
- `Main.java` – Java source code
- `output.txt` – sample output

## How to run
Open a question folder in VS Code / terminal and run:

```bash
javac Main.java
java Main
```

For Q6, enter `Java` when prompted to get the shown sample output.

## Notes
- Q4 uses HashSet; its display order is not guaranteed by Java.
- Q10 demonstrates that ArrayList keeps duplicates and insertion order, while HashSet stores unique values and does not guarantee order.
- Q15 uses a fixed sample set of five students to demonstrate add, remove, search, display, count, unique IDs, sorted IDs and ListIterator traversal.
- Outputs are sample runs; collection ordering may vary where the Java collection does not guarantee order.
