# Java Lab Sheet 8 – Generics

**Total questions:** 15

Each question folder (`Q01` to `Q15`) contains its Java source code and sample output.

## Compile and run
Open a question folder in terminal:

```bash
javac ClassName.java
java ClassName
```

Replace `ClassName` with the Java filename without `.java`.

## Notes
- Q11 sample input is `50`; enter another number to test other results.
- Generic type parameters provide compile-time type safety.
