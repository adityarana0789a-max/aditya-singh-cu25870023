# Java Lab Sheet 05 — Foundations of Java Development

BCA III Semester (2026–2027)

This repository contains solutions for all 20 questions from Lab Sheet-05.
Each question folder contains:
- A Java source file (`.java`)
- Sample program output (`output.txt`)

Topics: Encapsulation, getters and setters, validation, single/multilevel/hierarchical inheritance,
method overriding, interfaces, multiple inheritance through interfaces, and hybrid inheritance.

## How to run
Open a question folder in a terminal and run:
```bash
javac ClassName.java
java ClassName
```
Replace `ClassName` with the public class name in that question's Java file.
